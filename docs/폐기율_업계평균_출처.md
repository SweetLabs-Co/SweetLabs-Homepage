## 판정 (v1 대비 변경: 있음, 한 단계 낮춤)

**v1 "일부 뒷받침" -> v2 "국내 근거 없음(뒷받침 못 함). 유일한 국내 같은 정의 숫자는 오히려 0.83%보다 낮음."**

1. 필요 조건: 업계 평균 약 4.2%~8.3% (0.83 x 5 = 4.15, 0.83 x 10 = 8.3).
2. 국내에 신선식품 제조업의 '제조 단계 폐기율(%)' 공식 평균은 **없다**(전수 확인): 정부 통계는 폐기량(톤)만 있고 비율이 없으며, KREI 2024는 "우리나라는 식품손실지수를 개발하지 않고 있다"고 직접 적었다(출처 2, 3).
3. 국내에서 0.83%와 같은 방식(완제품 손실폐기 / 생산량)으로 공시한 숫자는 CJ제일제당 0.31%(2025)뿐이다(출처 1). 업계 평균이 4~8%라는 주장과 맞지 않는다. 단 CJ는 상온·냉동 중심이라 신선식품 대표값은 아니다.
4. 해외 제조업 숫자(영국 3.8%)는 1/5에 못 미치는 약 1/4.6이고, 분모·범위가 다르다. "1/10"(8.3%)을 받치는 제조업 숫자는 어디에도 없다.
5. 따라서 "업계 평균 1/5~1/10"은 현재 공개 근거로 **단정 불가**. 아래 대안 문구 권장.

## 정의 차이 (각주에 반드시 명시)

1. 분자: 완제품 폐기만 / 기부 포함 / 원재료 손질·공정손실 포함 / 반품·유통기한 경과 포함 중 어느 것인지. CJ=완제품 손실폐기(기부 포함), WRAP=가식+비가식 전체.
2. 분모: 생산량(CJ) / 취급·투입량(WRAP) / 매출(ReFED) / 입고·발주량(편의점). 분모에 따라 값이 크게 달라 섞어 평균 불가.
3. 범위: 우리는 단기 유통기한 신선식품. CJ·WRAP은 장기 유통 포함 평균. 신선식품 제조업 단독 평균은 공개 통계 없음(확정).
4. 단계: 제조 vs 소매(편의점 5~10%)·이커머스(컬리 1% 미만)는 별개.
