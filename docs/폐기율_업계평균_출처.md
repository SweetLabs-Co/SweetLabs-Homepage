# 홈페이지 "0.83% 폐기율 (업계 평균 1/5~1/10)" 출처 조사

- 조사일: 2026-11-15 · 조사: 윤회(집현전) · 대상: SweetLabs-Homepage index.html 912~913줄
- 검색에는 공개 자료만 사용(회사 내부 자료 미투입). 신뢰도 등급: S 정부·연구 / A 언론 / B 협회 / C 블로그 / U 불명

## 요약 판정

**"1/5~1/10" = 일부 뒷받침(국내 제조업 평균으로는 안 됨).**

- 필요 조건: 업계 평균 약 4.2%~8.3% (0.83 x 5 = 4.15, 0.83 x 10 = 8.3).
- **국내 신선식품·신선편의식품 제조업의 공식 평균 폐기율은 이번 조사에서 찾지 못함**(식약처·농식품부·aT·환경부·KREI 모두 제조 단계 폐기율 %를 따로 공표한 것 미확인).
- 가장 가까운 공개 숫자는 해외 제조업(영국 3.8%, 미국 7%)과 국내 편의점 간편식(5~10%)인데, 셋 다 정의가 우리 0.83%와 다르다. 이 숫자들이 4.2~8.3% 범위에 걸치긴 하지만, 서로 다른 정의를 섞은 것이라 "1/5~1/10"을 업계 평균 근거로 단정하긴 어렵다.
- 따라서 지금 문구는 출처 각주 없이는 근거 약함. 아래 대안 문구 권장(최종 결정은 대표).

## 정의 차이 (반드시 각주에 명시할 것)

1. 분자: 우리 0.83%가 무엇인지(완제품 폐기만? 원재료·공정손실 포함? 반품·유통기한 경과 포함?) 확인 필요(내부 정의는 이 조사에서 보지 않음). WRAP 3.8%는 원재료·공정 손실·비가식부 포함 폭넓은 정의.
2. 분모: 생산량 / 투입량 / 출고량 / 매출 중 무엇인지에 따라 값이 크게 달라짐. WRAP=취급 식품 총량, ReFED=매출 금액, 편의점=입고 수량.
3. 범위: 우리는 신선편의식품(유통기한 짧음). WRAP·ReFED는 전 식품 제조업 평균(유통기한 긴 제품 포함). 신선편의식품 단독 평균은 공개 통계 미확인.
4. 단계: 제조사 폐기 vs 소매 폐기(편의점)는 별개. 소매 폐기율(5~10%)을 제조 평균으로 쓰면 오해 소지.
